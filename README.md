Web iOS - Browser Operating System


A lightweight, web-based iOS simulator that runs entirely in your browser using standard web technologies. Experience an Apple-inspired operating system environment directly from a single HTML entry point without any server dependencies or build steps.


🌟 Features

Instant Launch: Runs directly by opening index.html in any modern web browser.

Authentic iOS UI: Includes the iOS dock, lock screen, status bar, control center, and smooth app animations.

Built-in Web Apps:


Safari: Simulated web browser frame.

Notes: Persistent note-taking app using browser localStorage.

Calculator: Fully functional standard calculator.

Settings: Customizable wallpaper, display options, and theme toggle (Light / Dark Mode).

Clock: Real-time clock with alarm and timer utilities.

Responsive Layout: Optimized for desktop monitors and mobile touch displays.
